Presentation Timekeeper PWA

To install on iPhone:
1. Upload all files in this folder to a static HTTPS web host (for example Netlify Drop or GitHub Pages), keeping the folder structure intact.
2. Open the resulting HTTPS URL in Safari on iPhone.
3. Share > Add to Home Screen > Add (choose Open as Web App if prompted).
4. Open the home screen icon once while online to cache the app for offline use.

Opening index.html as a local file will not enable PWA installation/service-worker offline caching.
Data stays in localStorage on the device. Back up regularly using Backup JSON. Keep the app visible during timing; iOS background suspension and system clock changes may affect accuracy. Not a clinical-grade timekeeping instrument.
